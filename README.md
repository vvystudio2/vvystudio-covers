# vvystudio-covers｜一次制作五版视频封面

给出标题、文字颜色和人物照片，让 AI agent 按 vvystudio 的视觉规则，生成五张适用于不同画幅的视频封面。

这是一套采用 [Agent Skills 格式](https://agentskills.io/specification) 的通用封面工作流，不绑定某个 agent、模型厂商或固定的工具名称。它不包含图像模型；能否实际出图，取决于 agent 接入的图像工具。

## 不同 agent 怎么用

| 环境 | 加载方式 | 执行结果 |
| --- | --- | --- |
| 原生支持 Agent Skills | 按所用平台的方式导入整个 `vvystudio-covers` 文件夹 | agent 读取 `SKILL.md`，使用自身已提供的图像能力执行 |
| 不支持自动加载 Skill，但能读取文件或附件 | 让 agent 阅读 `SKILL.md`，同时提供人物照片和所需参考图 | 使用同一套制作规则；工具调用由该 agent 按实际接口适配 |
| 只能接收文本或没有生图工具 | 把正文作为任务规则提供给 agent | 可整理需求并输出五版提示词；不会自动获得生图能力，也不能宣称已经生成图片 |

这是按能力适配的设计说明，不是对所有 agent 产品的实测兼容承诺。不同平台的技能导入入口、图片限制和输出方式以该平台为准。

## 能做什么

- 一次交付五张独立图片，包含三种中文人物版、一张无人物版和一张 YouTube 英文人物版。
- 根据标题自动选择相关主题元素；涉及真实产品时，优先检索并核对官方素材。
- 同一套人物、主题元素和配色，按不同画幅重新布局。
- 支持分词指定文字颜色，例如 Codex 淡紫色、Claude 橙色，其余文字白色。
- 使用暗调、高对比、超大粗体、轮廓光与适量体积光，保持标题清楚、元素完整。
- 检查文字、人物、图标、配色、边缘与实际宽高比，保存 PNG 文件并提供预览和下载链接。

## 五种输出

| 版本 | 比例 | 人物 | 默认导出尺寸 |
| --- | --- | --- | --- |
| `portrait-3x4` | 3:4 | 有 | 1200 × 1600 |
| `landscape-4x3` | 4:3 | 有 | 1600 × 1200 |
| `wide-16x9` | 16:9 | 有 | 1920 × 1080 |
| `object-3x4` | 3:4 | 无 | 1200 × 1600 |
| `youtube-en-16x9` | 16:9 | 有 | 1920 × 1080 |

前四版保留原始标题；第五版自动转换为自然、简洁的英文标题。也可以使用用户提供的英文标题。

## 使用前需要准备

1. **标题**：前四版逐字保留，允许按画幅分行。
2. **文字颜色**：可分别指定品牌、词语或其他标题部分的颜色。
3. **人物照片**：使用本次提供的照片作为人物参考。

也可以提供产品图片、参考封面、背景偏好或其他明确要求。没有指定主题元素时，工作流会根据标题自动选择。

## 使用示例

通用方式：附上 `SKILL.md`、人物照片和配套参考图，输入：

```text
请读取附件中的 vvystudio-covers/SKILL.md，按其中规则制作五版视频封面。
标题：Codex和Claude 差在哪？
文字颜色：Codex 为淡紫色，Claude 为橙色，其余文字白色。
人物照片：使用本次附件。
```

已经原生安装技能时，按所用 agent 的调用方式启动；例如支持 `$技能名` 的环境可使用 `$vvystudio-covers`，其他环境无需使用这一语法。

如需特别的动作或表情，可在请求中明确说明，例如：

```text
人物双臂张开，闭眼微微抬头，像是被救赎了一样，迎接从上方落下的圣光。
```

默认规则要求尽量保留原照的姿势与表情。明确要求改变动作时，以当前用户请求为准；新动作、手臂和表情需要生成，不能视为未经改动的原照片抠图。

## 加载技能

将整个技能文件夹导入所用 agent 的技能目录，或作为任务附件提供，并保留下面的相对路径结构。没有跨所有产品通用的安装目录，不要求使用某个本机路径。

```text
vvystudio-covers/
├── SKILL.md
├── README.md
├── agents/
│   └── openai.yaml
└── assets/
    └── object-layout-reference.png
```

- [`SKILL.md`](SKILL.md)：完整工作流和视觉规则。
- [`agents/openai.yaml`](agents/openai.yaml)：可选的 OpenAI 界面元数据；核心工作流不依赖此文件，其他 agent 可以忽略。
- [`assets/object-layout-reference.png`](assets/object-layout-reference.png)：无人物版的布局参考，仅继承构图和层级，不固定复用其产品、标题或颜色。

## 工具依赖与实际限制

- 要实际制作人物封面，需要支持参考图的图像生成或编辑能力；可以使用宿主已提供的内置工具、连接器或 API，不限定工具名称或模型品牌。
- 图片查看、素材检索、文件保存和尺寸读取按环境能力适配。缺少某项能力时，交付中明确指出未核验部分，不编造视觉检查、尺寸或下载链接。
- 不要求终端、Shell、Git、Notion 或额外账号。需要检索素材时优先使用现成工具；没有检索能力时使用可核对的用户素材或明确的概念元素。
- 字体渲染、人物身份、手部结构和图标细节都可能出现误差，需要检查并针对问题修正；不保证人物逐像素一致。
- 修改人物姿态与表情属于 AI 重绘，可能带来五官或身体细节变化。
- 没有图像工具时，必须明确说明未完成生成，可以提供提示词，不能把提示词当作已生成图片交付。
- 默认另存输出，保留原照片和已有版本；不会自动发布到公开平台或创建定时任务。

## 输出位置

用户指定位置优先，其次遵循宿主环境的输出约定；均未指定且有可写文件系统时，使用当前项目的 `output/covers/<本期标题>/`。没有文件系统时，返回平台原生图片或附件，不强制落盘到某个目录。
